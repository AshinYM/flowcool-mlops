# Flowcool — 예지정비 모델 운영 실험

센서 시계열로 냉각 압력 과다 정비까지의 TTF를 예측하고, FastAPI·MLflow·변화 감지·재학습·검증 게이트를 연결한 팀 프로젝트의 코드 검토본입니다.

## 포함 범위

- `phm/`: 시퀀스 구성, 학습·평가, 서빙·운영·재학습 구간 관리
- `serving_app/`: PHM 서버 진입점과 대시보드
- `tests/`: 원본 프로젝트의 검증 코드(일부는 외부 데이터 필요)
- `data/phm2018/prepare_dataset.py`: 원본 보유자가 집계 데이터를 만드는 코드

## 실행 전 준비

Python 3.11 환경에서 `pip install -r requirements-phm.txt`로 의존성을 설치합니다. TensorFlow·MLflow를 포함해 설치 용량이 큽니다. 원본 데이터는 배포하지 않습니다. 적법하게 확보한 PHM 2018 자료를 별도로 준비하고 데이터 준비 코드를 검토해야 합니다. 데이터가 없는 상태에서 학습·전체 검사가 성공한다고 주장하지 않습니다.

단일 장비의 train/validation/test CSV를 `data/phm2018/`에 준비한 후 `python -m phm.train`, `python -m phm.evaluate`를 실행합니다. 서버는 `uvicorn serving_app.phm_main:app --host 127.0.0.1 --port 8078`입니다. 원본의 빌드 중 학습 Dockerfile은 데이터가 빠진 이 사본에서 작동하지 않아 제외했습니다.

## 평가에서 지킬 점

실험 기록은 독립 평가에서 상수 기준 모델보다 부족한 구간과 fleet 후보 승격 차단을 명시했습니다. 현장 성능·실시간 수집·상용 배포를 검증한 서비스가 아닙니다. TTF는 익명화된 원본 단위이며 초·시간으로 환산하지 않습니다. 입력 변화와 정답 기반 성능 변화는 구분합니다.

다음 개선: 데이터 재배포 조건 확인 → 재현 가능한 합성 smoke fixture → 데이터와 이미지 빌드 분리 → 게이트·재시작·복구 검증.

## 출처와 개인 개선 기록

이 저장소는 기존 학습·팀 프로젝트에서 포트폴리오 후보를 선별한 **공개 포트폴리오 출발본**입니다. 사용자 확인에 따라 공개하되, 수업·팀 프로젝트를 기반으로 한 응용임을 밝힙니다. 전체를 처음부터 독자 구현했다고 주장하지 않습니다. 개인 개선은 커밋과 검증 결과로 구분해 쌓아갑니다. 원저작물에 임의의 라이선스를 부여하지 않았습니다.

교안·녹취록·실제 데이터·모델 파일·DB·API 키·실행 출력은 포함하지 않습니다. 노트북 출력은 제거했습니다. 과거 결과는 이번 재실행 결과가 아닙니다.
